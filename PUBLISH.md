# Публикация мода

Пошаговый план: от файлов в этой папке до мода в Zen Mod Store.

## 1. Создать репозиторий на GitHub

На этой машине `git` и `gh` уже установлены, а `gh` авторизован под `danonchek51`.
Самый быстрый путь — готовый скрипт в рабочей папке:

```powershell
python publish_github.py             # показать план
python publish_github.py --publish   # создать репозиторий, запушить, сделать релиз v1.10.0
```

Скрипт сам создаст публичный репозиторий `danonchek51/zen-essentials-folders`,
заложит исходники, поставит тег `v1.10.0` и создаст релиз с архивом во вложении.

Вручную то же самое:

```powershell
cd путь\к\Zen-Essentials-Folders
git init
git add .
git commit -m "Essentials Folders: first release"
git branch -M main
git remote add origin https://github.com/danonchek51/zen-essentials-folders.git
git push -u origin main
```

Если `git` не установлен — скачать с <https://git-scm.com/downloads>, затем:

```powershell
git config --global user.name "Ваше имя"
git config --global user.email "ваша@почта"
```

## 2. Проверить адрес в манифесте

В `theme.json` должно стоять:

```json
"homepage": "https://github.com/danonchek51/zen-essentials-folders"
```

и поле `"author"` — по вашему желанию (сейчас «Essentials Folders»).

Быстрая проверка, что заглушка не осталась:

```powershell
Select-String -Path theme.json -Pattern "YOUR-NICK"
```

## 3. Проверить, что мод ставится «с нуля»

На чистом профиле (или в текущем, но с отключённым модом):

1. Закройте Zen.
2. `python install.py` — скрипт найдёт профиль и поставит мод.
3. Запустите Zen: плитки должны появиться в «Важных».

## 4. Опубликовать мод

### 4.1. GitHub Releases — основная площадка

Репозиторий + релиз с архивом мода. Из него мод ставят и вручную
(`python install.py`), и через Sine.

```powershell
python publish_github.py --publish
```

### 4.2. Sine Store — маркетплейс модов (главный)

Sine — тот самый менеджер модов, который стоит внутри Zen
(`chrome/sine-mods` в профиле). В его маркетплейс попадают **моды со
скриптами** — в отличие от официального реестра Zen.

Заявка: issue в `sineorg/store` с шаблоном `add-theme`, в котором нужно
одно поле — ссылка на репозиторий:

- Адрес: <https://github.com/sineorg/store/issues/new?template=add-theme.yml>
- Title: `[add-theme]: Essentials Folders`
- Theme Homepage: `https://github.com/danonchek51/zen-essentials-folders`

Готовый текст — в файле `store-submission.md`.

После публикации мод появится в Zen: Настройки → Sine Mods → Marketplace.
Sine сам подтягивает новые версии из репозитория — обновлять вручную не нужно.

Пользователь может поставить мод и без магазина: в Zen → Настройки → Sine Mods →
«Установить из репозитория» и вставить ссылку на наш репозиторий.

### 4.3. Официальный реестр Zen (zen-browser.app/mods) — не подходит

Реестр на <https://zen-browser.app/mods/> заполняется автоматически: бот
(`zen-browser/theme-store`) читает заявку и **сам собирает** `theme.json`.
В собранном манифесте есть только `style` (CSS), `readme`, `image` и
`preferences` — поля `scripts` там нет, а установщик Zen
(`ZenMods.installMod`) скачивает только `chrome.css`, `readme.md` и
`preferences.json`.

Вывод: мод, которому нужен скрипт (а это наш мод), через этот реестр
установить нельзя — скачается только CSS, и плиток не будет. Поэтому заявку
в `zen-browser/theme-store` **не подаём**; правильная площадка для модов со
скриптами — Sine Store (4.2).

Если мейнтейнеры реестра расширят формат и добавят `scripts`, заявка
оформляется по шаблону `create-theme`:

| Что | Требование | У нас |
|---|---|---|
| Имя мода | уникальное, меньше 25 символов, только буквы/цифры/пробел | `Essentials Folders` — 18 ✔ |
| Описание | меньше 100 символов | `Folder tiles for Zen Essentials: nesting, drag & drop, search and settings.` — 75 ✔ |
| Image | PNG **600×400** по HTTPS | нужен живой снимок из Zen |
| Theme Styles | CSS (без `@-moz-document url-prefix('chrome://')`) | наш `chrome.css` ✔ |
| Readme | обязателен | ✔ `README.md` |
| Preferences | JSON | ✔ `preferences.json` (5 старых настроек) |

### 4.4. Прочие места

- **Коллекции community-модов** — репозитории вида `baxyz/zen-mods`: там другой
  формат (`mod.json` + `userChrome.css`), поэтому нужен отдельный конвертер.
  Необязательно.
- **Своя страница на GitHub** — README репозитория и есть витрина мода.

## 5. Что должно лежать в репозитории

```
theme.json              — манифест мода (обязательно)
preferences.json        — настройки мода (обязательно)
chrome.css              — стили (обязательно)
essentials-folders.uc.js— скрипт (обязательно)
README.md               — описание со скриншотами
LICENSE                 — лицензия
install.py              — автоустановка вручную (для тех, кто не из Store)
images/                 — скриншоты для README
```

## 7. История версий

- **1.10.0** — у мода появились **собственные настройки**: диалог «Настройки мода»
  (шестерёнка `⚙` у строки поиска или пункт в меню папки) с 21 параметром в
  четырёх группах: плитки папок, сетка иконок, индикаторы и поведение. Всё
  применяется сразу, без кнопки «Сохранить»; есть «Сбросить». Новые настройки
  лежат в одном JSON-префе `zen.essentialsfolders.settings`, пять старых префов
  по-прежнему читаются и работают. Появился **индикатор активной папки** —
  папка, в которой лежит текущая вкладка, помечается и мягко пульсирует: по
  умолчанию свечением рамки (рамка видна всегда, пульсирует ореол вокруг неё —
  так индикатор читается при любом цвете папки и в любой теме), либо точкой,
  уголком или звёздочкой в углу плитки. Пульсацию можно выключить, её скорость
  настраивается. Размеры плиток, шаг иконок, воздух и зазоры переведены на
  CSS-переменные и стали настраиваемыми; вид счётчика, значок вложенности и
  метка выгруженной вкладки тоже вынесены в настройки.
- **1.9.0** — переработан вид плиток и исправлены перетаскивание с иконками.
  Плитки папок теперь лежат отдельной полосой на всю ширину панели и делят её
  поровну: расширил сайдбар — плитки стали шире (раньше их размер вообще не
  зависел от ширины панели). У плиток одинаковая высота, название не обрезается,
  счётчик стал аккуратным бейджем, а «+» — отдельной кнопкой в конце ряда.
  У вложенной папки теперь аккуратный шеврон слева от иконки: раньше символ «↳»
  наполовину срезался скруглённым углом плитки и читался как случайная цифра.
  Перетаскивание вкладки в папку работает и для вкладок, начатых в сайдбаре:
  мод берёт вкладку из буфера перетаскивания, а не полагается только на событие
  старта. Если бросок не сработал, мод объясняет почему короткой подсказкой.
  Логотипы сайтов больше не пропадают: значок, пришедший позже, дожидается
  своей загрузки — и панель перепроверяет иконки ещё дважды после перестроения.
- **1.8.2** — раскрытая папка выглядит аккуратнее: колонки иконок тянутся на всю
  ширину панели (шапка и иконки стоят на одной линии, размер панели не влияет),
  вокруг каждого логотипа одинаковый воздух (10 px), цветная плоскость заканчивается
  сразу под последней иконкой — пустоты снизу больше нет. Иконки родительской папки
  больше не продолжают ряд вложенной: после открытой вложенной папки они начинают
  новый ряд (с отступом 12 px) и не попадают в её цвет — раньше плоскость вложенной
  папки накрывала иконки родителя, и они выглядели как содержимое вложенной папки.
  Соседние открытые папки больше не наезжают друг на друга: между цветными
  плоскостями появился зазор, и шапка следующей папки больше не закрывается.
  Панель не копит старые разрывы: после открытия и закрытия вложенных папок
  в списке не остаётся пустых дыр между иконками.
- **1.8.1** — цвет папки применяется сразу после «Сохранить» (раньше он мог
  появиться только после следующего события); список доменов в папке больше не
  переписывается при смене цвета или имени; в диалоге работает `Ctrl+Enter`;
  все логотипы в «Важных» теперь в одинаковой ячейке (26 px) и стоят ровной
  сеткой с одинаковым шагом; у выгруженной из памяти вкладки вокруг логотипа
  появляется рамка (мод определяет выгрузку сам — Zen сразу снимает свой признак
  «выгружено»). Настройка «Не растягивать мелкие иконки сайтов» убрана —
  иконки всегда одного размера.
- **1.8.0** — цвет папки можно выбрать любой: в диалоге папки появилась пипетка
  (квадрат оттенка + полоса цвета), поле для точного кода (`#rrggbb`) и кнопка
  «Случайный». Раньше были только 16 предустановленных цветов.
- **1.7.1** — колесо мыши над панелью папок прокручивает саму панель (Zen перехватывал
  прокрутку сайдбара), на краю панели колесо уходит в список вкладок; цветные плоскости
  папок больше не «уезжают» от своих папок при прокрутке панели.
- **1.7.0** — броски попадают в цель с первого раза (запоминается раскладка плиток
  в начале перетаскивания, гасится лишний клик после броски), бросок обычной вкладки
  на плитку сайта, иконки не растягиваются (мелкие рисуются в натуральную величину),
  вместо пустой плитки — первая буква адреса на цветном круге, поиск по папкам,
  закрепление папки вверху (пинка) с жёлтой точкой в углу плитки (и на шапке открытой
  папки), «открыть все вкладки папки», «развернуть/свернуть всё», меню по правому клику
  на шапке открытой папки, панель папок ограничена по высоте и прокручивается сама —
  список вкладок под ней больше не закрывается.
- **1.6.0** — правки броска и иконок: снимок раскладки плиток, зоны приёма,
  буква-заглушка для сайтов без favicon.
- **1.5.0** — перенос между папками переносит ровно одну вкладку: для адресов с путём
  в папке появляется точечное правило (`github.com/dano-/zef`), в прежней папке доменное
  правило остаётся, а конкретный адрес исключается (`!github.com/dano-/zef`).
  Появилось правило для главной страницы сайта (`github.com/`), у правил пути появилась
  граница (`zef` не ловит `zef2`), точечные правила и исключения видны в диалоге папки.
- **1.4.0** — открытая папка разворачивается в широкую цветную плоскость (без дублирования
  плитки), вложенные папки любой глубины, перестановка папок и плиток внутри папки
  перетаскиванием, зона приёма — сама открытая папка, самая свежая открытая папка сверху,
  плоский минималистичный вид без тёмных подложек.
- **1.3.0** — крупные логотипы в «Важных» (26 px) без приглушения Firefox/Zia,
  тёмная подложка у выгруженных плиток, иконки в списке вкладок 18 px,
  два новых поля размера в настройках мода.
- **1.2.0** — перетаскивание вкладок в папки и обратно на разделитель.
- **1.1.0** — ряд плиток в одну линию, шапка раскрытой папки, разделитель.
